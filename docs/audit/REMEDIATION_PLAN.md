# Gelato Central — Σχέδιο διόρθωσης

Κάθε βήμα είναι ένα μικρό, απομονωμένο commit με το δικό του test, σε ένα PR υλοποίησης. Η σειρά βγαίνει από: επίπτωση στη δουλειά του καταστήματος, τεχνικό ρίσκο, κόπο. Οι κωδικοί ευρημάτων παραπέμπουν στο `AUDIT_REPORT.md`.

**Κόπος**: Μ = μικρός (έως μισή μέρα), Με = μεσαίος (έως δύο μέρες), Μγ = μεγάλος.
**Migration**: όπου γράφει «Ναι» είναι πάντα προσθετικό (νέα nullable στήλη, ευρετήριο ή περιορισμός) και ακολουθεί τους κανόνες του `DATABASE_REVIEW.md`. Κανένα βήμα δεν σβήνει στήλη, πίνακα ή δεδομένα.

Ισχύουν σε όλα: κανένα νέο πακέτο, καμία αναβάθμιση framework, καμία αλλαγή σχεδίασης, το συμβόλαιο του API των συσκευών μόνο μεγαλώνει (νέα προαιρετικά πεδία), ποτέ δεν αλλάζει.

Οι Φάσεις 3 έως 5 και η P ακολουθούν στο ίδιο PR, με τη σειρά που γράφονται. Όσα περιμένουν απόφαση (3.6, 3.7, 3.8, 4.4 για το κλείσιμο, 5.4, Φάση 6) μπαίνουν μόλις απαντηθούν· αν δεν απαντηθούν, το PR παραδίδεται χωρίς αυτά και καταγράφονται ως ανοιχτά.

Αναίρεση: κάθε βήμα είναι ένα commit, άρα αναιρείται με `git revert` χωρίς να παρασύρει άλλο. Τα migrations είναι προσθετικά, άρα ο προηγούμενος κώδικας τρέχει και με το νέο schema.
