## Υποδομή (βήματα 5.1 και 5.2 του σχεδίου, γίνονται πρώτα)

1. **`npm run test:integration`**: τρέχει και τα 23 αρχεία με `--test-concurrency=1`.
2. **Προστασία βάσης**: κοινή συνάρτηση που αρνείται να τρέξει αν το όνομα της βάσης δεν τελειώνει σε `_test` ή `_audit`, ή αν ο host δεν είναι τοπικός. Έτσι κανένα test δεν γράφει ποτέ σε παραγωγή.
3. **GitHub Actions** σε κάθε PR και push στο `master`: `npm ci`, `npx next typegen`, `npx tsc --noEmit`, `npm run lint`, `npm test`, `prisma migrate deploy` και `npm run test:integration` σε υπηρεσία `pgvector/pgvector:pg16`, `npm run build`. Χωρίς κανένα μυστικό.
4. **Έλεγχος απόκλισης schema** στο CI: `prisma migrate diff` με `--exit-code`.

## Δικαιώματα και απομόνωση (νέο, μία φορά)

Ένα integration test που, για κάθε server action και route που δέχεται id, δοκιμάζει τρία πράγματα με δύο επιχειρήσεις στη βάση: χωρίς σύνδεση, με χρήστη χωρίς το δικαίωμα, με χρήστη άλλης επιχείρησης. Και τα τρία πρέπει να απορρίπτονται και η βάση να μένει ίδια. Ξεκινά από τα actions χρημάτων και αποθέματος και μεγαλώνει σταδιακά.

## Τελική επικύρωση (φάση 5 της εργασίας)

Σε προσωρινή τοπική βάση με τα migrations του PR και το demo seed:

1. Όλα τα unit και integration tests, typecheck, lint, production build.
2. **Κρίσιμες ροές με το χέρι σε browser** (μία φορά η καθεμία, σε 360px και 1280px):
   - σύνδεση, λάθος κωδικός, κλείδωμα, επαναφορά κωδικού
   - σύζευξη συσκευής, πώληση από το ταμείο του browser, πιστωτικό
   - παραλαβή αγοράς, καταχώρηση τιμολογίου, πληρωμή προμηθευτή
   - παραγωγή παρτίδας, κλείσιμο ημέρας
   - μεταφορά και απογραφή αποθέματος
   - παραγγελία χονδρικής, τιμολόγιο, είσπραξη
   - άνοιγμα συνδέσμου B2B, RFQ, βιτρίνας και βαρδιών χωρίς σύνδεση
   - εξαγωγή λογιστή και εξαγωγή επιχείρησης
3. **Συμβόλαιο API**: τα contract tests του 1.2 τρέχουν και με τα αιτήματα του παλιού `mobile/api.ts` (πριν από το 1.7), για να αποδειχθεί ότι το παλιό APK συνεχίζει να δουλεύει.
4. **Βάση**: `prisma migrate diff` χωρίς απόκλιση· migrations πάνω σε βάση με δεδομένα· επαναφορά backup σε άδεια βάση και σύγκριση πλήθους γραμμών (βήμα 5.4).
5. **Ασφάλεια**: το test δικαιωμάτων, οι κεφαλίδες απόκρισης, `npm audit`.

## Τι δεν μπορεί να δοκιμαστεί από εδώ

- **Πραγματική πληρωμή με Viva Terminal σε συσκευή Android.** Θέλει συσκευή και δοκιμαστικό λογαριασμό Viva· ο κώδικας ελέγχεται με ψεύτικο πάροχο και το πραγματικό το δοκιμάζει άνθρωπος πριν από τη διανομή του APK.
- **Διαβίβαση στο myDATA** πέρα από τα υπάρχοντα tests με ψεύτικες απαντήσεις.
- **Συμπεριφορά στην παραγωγή**: proxy του Coolify, πραγματικός όγκος, πραγματικό backup.

Το `FINAL_REPORT.md` θα γράφει για καθένα από αυτά «δεν δοκιμάστηκε», και η εφαρμογή δεν θα χαρακτηριστεί έτοιμη για παραγωγή σε ό,τι στηρίζεται πάνω τους.
